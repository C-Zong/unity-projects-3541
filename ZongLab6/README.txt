🎮 User Input (Unity Editor Configuration)

Script is attached to the Main Camera object.
- Distance To Plane: Distance from the camera to the projection plane
- Pixel Width: Pixel width on the plane
- Pixel Height: Pixel height on the plane
- Image Width: Number of pixels per row
- Image Height: Number of pixels per column
- Max Ray Distance: Maximum ray tracing distance

Created image files will be saved in:
Assets/ZongData/
Example Images are saved in:
Assets/ZongData/ExampleImages
